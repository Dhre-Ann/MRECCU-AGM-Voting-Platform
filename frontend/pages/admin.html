Reset current race only

Zeros tallies for the live race only, then clears every voter’s has voted flag. Other completed races are not touched.

No race is currently active. This reset is only available during a live race.

  • This race: voting stopped, marked incomplete, paper tallies unlocked

  • Every voter: has voted cleared

Full election reset

This wipes the current election so staff can start over. It does not delete voters or candidates.

  • Every position: voting stopped, marked incomplete, paper tallies unlocked
  • Every candidate, every race: vote count set to 0
  • Every voter: has voted cleared
